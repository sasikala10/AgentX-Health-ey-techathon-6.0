# AgentX Health – AI-Powered Doctor Verification System

## Project Overview
AgentX Health is an AI-driven system that automates the verification of doctor information across multiple departments. It helps healthcare administrators maintain accurate and up-to-date provider data, improving patient experience and ensuring regulatory compliance.

This prototype is built using **Streamlit**, allowing an interactive demonstration of doctor verification dashboards and analytics.

---

## Features
- **Automated Verification Dashboard:** Visualize verification status across departments.
- **Department-Wise Insights:** Bar graph showing number of verified doctors per department.
- **Verification Response Analysis:** Histogram showing response times for verification.
- **Accuracy Tracking:** Heat map representing verification accuracy across departments.
- **Interactive Prototype:** Fully functional Streamlit interface for exploring the data.
